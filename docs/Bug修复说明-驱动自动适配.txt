==============================================
 ASIO Bridge 更新说明
 Bug 修复：输出设备驱动自动适配
==============================================

一、问题现象
----------------------------------------------
在其他电脑上安装运行后，一直提示：

  输出后端初始化失败: 加载ASIO驱动失败: ASIO MADIface USB
  (请确认注册表 HKLM\SOFTWARE\ASIO 下存在该驱动)
  (2秒后重试)

原因：程序把 RME MADIface USB 写死为默认 ASIO 驱动。
其他电脑没有这个驱动（比如用 Realtek、Focusrite、
Scarlett 或其他声卡），所以永远加载失败、无限重试。

二、修复内容
----------------------------------------------
1. 去掉硬编码的默认驱动，启动时自动寻找可用设备：

   自动选择顺序：
   ① 设备列表中匹配到 ASIO 的端点（自动识别驱动名）
   ② 注册表里枚举到的第一个 ASIO 驱动
      （适用于纯 ASIO 声卡，没有对应 Windows 端点的情况）
   ③ 第一个 WASAPI 独占设备（没有 ASIO 时兜底）

2. 自动选中的 ASIO 初始化失败时，自动降级为
   WASAPI 独占输出，不再无限重试卡死。

3. 测试模式（--tone）同样自动选驱动。

三、改动效果
----------------------------------------------
以前：必须手动指定驱动，或安装 RME 设备才能用。
现在：任何电脑装上即用——
  · 有 ASIO 驱动（Realtek/Focusrite/Scarlett/声卡自带）→ 自动用 ASIO
  · 没有 ASIO → 自动用 WASAPI 独占
  · 控制台网页可随时手动切换设备

四、验证情况
----------------------------------------------
在本机（RME 设备关机状态）实测：
  自动选择 ASIO: Realtek ASIO
  48000 Hz / 2 通道 / 缓冲 528 帧 / 类型 Int24LSB
  桥接运行中 ✓

数值自检全部通过，无回归。

五、相关文件
----------------------------------------------
源码:  src/main.cpp（输出后端创建与自动适配逻辑）
更新:  桌面 asio_bridge_setup.exe（含本次修复）
