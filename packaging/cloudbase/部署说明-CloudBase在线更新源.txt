===============================================================================
 ASIO Bridge · 腾讯云 CloudBase 在线更新源部署指南
===============================================================================
（支持国内在线更新：检查/下载/校验/静默升级全链路）

一、为什么用 CloudBase 静态托管
------------------------------------------------------------------------------
  · 国内节点访问快（腾讯云 CDN）
  · 自带 HTTPS（WinHTTP 安全通道无障碍）
  · 免费额度足够（静态托管每月免费流量 + 存储）
  · 浏览器控制台上传文件即可，无需维护服务器

二、一次性部署步骤
------------------------------------------------------------------------------
1) 开通 CloudBase
   腾讯云控制台 → 云开发 CloudBase → 开通环境（选「按量付费」或免费套餐）
   记下「环境 ID」（形如 xxx-1a2b3c4d5e6f）

2) 启用静态网站托管
   环境 → 静态网站托管 → 开通（若未开通）
   得到默认域名：https://<环境ID>.tcloudbaseapp.com

3) 上传两个文件（静态托管 → 文件管理 → 上传）
   · asio_bridge_setup.exe        （安装包，本仓库 packaging\output\ 下）
   · version.json                 （清单，本仓库 packaging\cloudbase\ 下）

4) 修改 version.json 中的 url 为你的真实域名
   本仓库已预填环境 ID tuncloud-9933-d8gf22m5w52d15d13：
     https://tuncloud-9933-d8gf22m5w52d15d13.tcloudbaseapp.com/asio_bridge_setup.exe
   如使用其他环境，替换环境 ID 即可。
   （JSON 中不能有注释；改完重新上传覆盖）

5) 配置客户端
   在桥的 asio_bridge.cfg（安装目录下）加一行：
     update_url=https://tuncloud-9933-d8gf22m5w52d15d13.tcloudbaseapp.com/version.json
   重启桥 → 控制台顶部出现「检查更新」按钮 → 点一下应显示
   「已是最新版本 v1.0.0」（无报错即链路通）

   完整 URL 速查：
     exe  下载: https://tuncloud-9933-d8gf22m5w52d15d13.tcloudbaseapp.com/asio_bridge_setup.exe
     清单访问: https://tuncloud-9933-d8gf22m5w52d15d13.tcloudbaseapp.com/version.json
     cfg 配置: update_url=https://tuncloud-9933-d8gf22m5w52d15d13.tcloudbaseapp.com/version.json

三、发布新版本流程（以后每次更新）
------------------------------------------------------------------------------
1) 改代码 → 编译 → 打安装包（packaging\asio_bridge.iss → ISCC）
2) 修改 src\update_check.h 里的 kAppVersion 为新版本号（如 1.0.1）
   重新编译、重新打包
3) 上传新 asio_bridge_setup.exe 到 CloudBase 静态托管（覆盖旧文件）
4) 重新生成 version.json（版本号 + SHA256 用下面命令算）并上传覆盖
5) 用户端桥启动时自动发现新版本，控制台点「下载并升级」即可一键更新

生成 version.json 的 PowerShell 命令：
  $sha = (Get-FileHash .\asio_bridge_setup.exe -Algorithm SHA256).Hash.ToLower()
  $json = @"
  {
    "version": "1.0.1",
    "url": "https://tuncloud-9933-d8gf22m5w52d15d13.tcloudbaseapp.com/asio_bridge_setup.exe",
    "sha256": "$sha"
  }
  "@
  [System.IO.File]::WriteAllText(".\version.json", $json, [System.Text.Encoding]::UTF8)

四、验证清单（浏览器打开即可看到）
------------------------------------------------------------------------------
  https://tuncloud-9933-d8gf22m5w52d15d13.tcloudbaseapp.com/version.json
  应显示 JSON：{ "version": "...", "url": "...", "sha256": "..." }

五、常见问题
------------------------------------------------------------------------------
Q: 上传后访问 version.json 返回 404？
   A: 确认文件在静态托管根目录，且文件名完全一致（小写）。

Q: 桥显示「检查更新失败」？
   A: 先浏览器直接访问 update_url 看是否可达；确认 cfg 行无多余空格。

Q: 想隐藏安装包直链？
   A: CloudBase 支持静态托管自定义域名 + 访问控制，可加防盗链；
      清单内 sha256 已能防止篡改（校验失败会拒绝安装）。
